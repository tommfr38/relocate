Welcome to Relocate

Relocate is a location-simulation workspace for iOS development and QA — for iOS Simulators, and for physical iPhones connected by cable over Apple's trusted developer channel.

This installer will:

  • Install Relocate.app into your Applications folder
  • Install the open-source pymobiledevice3 command-line backend used for physical-device sessions, if it isn't already on this Mac

Requirements: macOS 14 or later, and Xcode with the iOS platform installed for physical-device support.

Use only with devices you own or are authorized to test.
