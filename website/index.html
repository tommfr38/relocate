Your iPhone stays stock

Nothing is jailbroken. Nothing is patched.

Relocate talks to your iPhone over the same developer channel Xcode uses. It sends a coordinate — that's the whole trick. iOS still reports the location as simulated, and pressing Stop hands control straight back to the real GPS.

How it works

Cable in. Pin dropped. Done.

1

Plug in and trust

Connect the iPhone with a data cable, unlock it, and tap Trust. Turn on Developer Mode once — Apple's own toggle.

2

Pick a spot

Click the map, paste coordinates, or pull up a saved place. Chain waypoints together if you want a moving route.

3

Set location

Your iPhone is there — every app on the device sees it. Press Stop whenever you want the real GPS back.

Features

Built for accuracy, not guesswork.

Pinpoint coordinates

Drop a pin on the map or type latitude and longitude to six decimal places. Whatever the test case needs.

Timed routes

String waypoints into a route and play it back at a set speed, from walking pace to motorway. The device moves smoothly, not in jumps.

GPX in and out

Import a recorded track to replay it on the device, or export a route you built to share with the rest of the team.

Saved places

Keep the spots you test against. Rename them, reorder them, drop back to any of them in a click.

It holds

A simulated fix normally gets overwritten by real GPS within seconds. Relocate keeps re-asserting it, so your location stays put.

Mac and PC

The same app on both. On a Mac it drives the iOS Simulator too, so you can test before a device is even plugged in.

FAQ

Questions, answered straight.

Does this need a jailbreak?
No. Relocate uses the developer channel Apple already exposes over USB — the same one Xcode's "Simulate Location" uses. Your iPhone stays completely stock.
Will apps see the simulated location?
Yes. It's set at the system level, so every app on the device reads the new location. Note that iOS still flags it as simulated — Relocate doesn't hide that, and some apps and games check for it.
Does my real location come back?
Immediately. Press Stop and the real GPS takes over. Nothing is left behind on the device.
Why does the location snap back on its own?
On a plain one-shot command it would — iOS overwrites a simulated fix with a real one within about five to ten seconds. Relocate re-asserts the coordinate on a short interval so it holds for as long as you want it to.
Do I have to stay plugged in?
Yes. Relocate works over the cable, and the session ends if you unplug or the phone locks. There's no wireless mode.
Why doesn't Windows see my iPhone?
Almost always because Apple Mobile Device Support isn't installed. Get the Apple Devices app from the Microsoft Store (or iTunes), reconnect, and press Refresh. The installer warns you if it's missing.
Is it really free?
Yes — no account, no licence key, no telemetry. The source is on GitHub if you'd rather read it or build it yourself.
What am I allowed to use it for?
The tool works on all applications however we only endorse using it for development and educational purposes. Do not break any program's TOS!
